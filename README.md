# Maquina virtual grupo 1A, hecho por: Lourdes Luna, Juan Cruz Paez y Tobias A. Gilardi  
Programa desarrollado para Windows.  
Requerimientos previos: Compilador de C (MinGW) y traductor assembler a lenguaje maquina (vmt).  
## Como ejecutar el programa  
Abrir el cmd en la carpeta donde este alojado el programa y ejecutar el comando:
`vmx archivo.vmx [-d]`  
**archivo.vmx** (obligatorio) : es el archivo que devuelve el traductor con el programa a ejecutar por la maquina.  
**-d** (opcional) : flag opcional para mostrar el codigo assembler del programa cargado en memoria.
